# 麻雀牌 写真認識テスト

HaseLabの2段階モデルをブラウザで試す独立テストです。既存の点数計算アプリには変更しません。

## GitHub Pagesへの配置
このフォルダの中身を別のテスト用リポジトリへ配置してください。`models/` の part00〜part08 は1ファイルずつアップロードして構いません。最終的に `models/` 内に全partが揃えば動作します。

## 処理
1. Tile YOLO (640x640 letterbox)で牌を検出
2. 検出牌を224x224へ切り出し
3. ImageNet正規化
4. ResNet-50で39クラス分類
5. 左から順に、牌種・分類信頼度・検出信頼度を表示

※ HaseLab公式はTile YOLOのセグメンテーションポリゴンから透視変換する方式を推奨しています。このテスト版はまず比較を容易にするため検出矩形で切り出します。
